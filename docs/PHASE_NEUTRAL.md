# Измерение петли «фаза-нуль»

Новая нативная страница DIAFAN:
`/services/izmerenie-petli-faza-nul/`.

Реализация подготовлена относительно GitHub main
`9db73a0b3e26f28a29b68d18bf5f0fc3a2e84d82`.
Публикация выполняется после локального просмотра владельцем сайта.

## Содержание

Ровно шесть блоков в порядке утверждённого ТЗ: первый экран, что проверяем,
когда нужны измерения, этапы и протокол, стоимость с формой, FAQ.
Публикационные тексты, цена от 9 900 ₽, состав комплекса, поля формы и SEO
сохранены. Редакционные указания, статистика запросов и нормативные источники
из ТЗ на страницу не выводятся. Ссылки внутри контента ведут только на сайт;
параметры `utm_source=chatgpt.com` из ссылок исходного документа удалены.

В новом шаблоне используются общие шапка, подвал, навигация, модальное окно,
Inter, контейнер, бумажный фон, графит и лайм. Фотография 1448 × 1086, WebP,
без надписей и логотипов, отображается целиком в пропорции 4:3 и использует
общую цветовую обработку сайта. Анимация учитывает prefers-reduced-motion.

Блоки после первого экрана оформлены отдельно: проверяемые действия занимают
четыре открытые колонки, ситуации — четыре компактные карточки с линейными
иконками, этапы — последовательную дорожку. Протокол выделен светлой врезкой.
Стоимость и форма собраны на светлом фоне, цена выделена графитом и лаймом.
На планшете этапы переходят в две колонки, на телефоне — в вертикальную
последовательность. Слова в заголовках подчёркнуты без изменения текста.
В первом экране исходное описание разделено на вводную фразу и два результата
работы. География и регистрация имеют отдельный второстепенный уровень;
цена с пояснением и кнопка объединены в предложение. Порядок текста из ТЗ
сохранён, фотография не менялась. Во втором блоке главный тезис выделен
типографикой, техническая область отделена от пояснения, четыре действия
образуют открытый горизонтальный ряд без карточек и изображений.

Обновлённого каталога «Услуги электроизмерительной лаборатории» с группой
«Электроизмерения и защитные меры» на текущей странице лаборатории ещё нет.
Обратная ссылка из этой группы откладывается до выпуска каталога, как
разрешено в разделе SEO исходного ТЗ. Существующий текст страницы лаборатории
этот патч не меняет. Ссылки с новой страницы на лабораторию, проверку автоматов
и комплексные испытания проверены: все три страницы отвечали HTTP 200.

## Заявки

Используется существующая форма DIAFAN 27 и её четыре поля. Их ID определяются
по типам, без изменения глобальных настроек формы. Телефон и согласие
обязательны; имя, email и описание объекта необязательны. Нативная проверка
остальных форм и запросов документов сохраняется.

Форма внутри контентной функции разворачивается штатным парсером DIAFAN:
одного вывода строки `<insert>` из функции недостаточно. Тест
`php scripts/test-phase-neutral-render.php` проверяет настоящий парсер,
контроллер и модель feedback с изолированными адаптерами БД: форму,
динамические ID полей, единственный honeypot, согласие, порядок блоков
и отсутствие неразвёрнутых вставок. При установке проверка запускается
до регистрации страницы; внешних отправок нет.

Сервисный режим проверяется сервером по опубликованной нативной странице.
Название услуги и URL определяются сервером. Поля сохраняются в feedback,
HTML-уведомление ставится в существующую очередь на office@nwdelectricity.ru,
данные попадают в действующий CRM/Hub-поток. Объект и рекламные параметры
остаются в нативном поле сообщения. Персональные данные не помещаются в URL
и параметры целей Метрики. Повтор одного request ID не создаёт дублей.

События Метрики 114341229:
`faza_nul_price_click` — клик по кнопке первого экрана;
`faza_nul_form_submit` — только подтверждённое сохранение заявки сервером.
При ошибке поля сохраняются, кнопка снова доступна. Автозаполнение и Enter
в текстовом поле сами не отправляют форму.

## Локальная установка

В архиве находятся `apply.ps1` и папка `payload`. Docker Desktop и локальный
сайт должны быть запущены. Установщик проверяет все хэши до копирования,
принимает CRLF в рабочих текстовых файлах, сохраняет резервную копию в
`.local/patch-backups/phase-neutral-*`, запускает проверки форм в контейнере
без внешних отправок и регистрирует страницу, метаданные и sitemap в БД.
В старых локальных дампах могут отсутствовать `nwd_feedback_request` и
`boykov_lead_outbox`. Установщик отдельным шагом с `NWD_LOCAL=1` создаёт только
отсутствующие таблицы для записи заявок и локальной очереди. Существующие
таблицы и записи не изменяются; DDL выполняется до транзакции страницы.
Добавленные пустые таблицы сохраняются при последующем откате файлов.
`--check` остаётся проверкой без записи. На Beget локальная подготовка не
выполняется: отсутствие таблиц останавливает публикацию с явной причиной.
При несовпадении файлов установка останавливается. Рабочие config.php,
SMTP, .htaccess, статьи, загрузки и другие страницы не заменяются.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$patch\apply.ps1" -ProjectRoot "C:\Users\user\WebstormProjects\nwdelectricity"
```

После `PHASE_NEUTRAL_LOCAL_OK` открыть
`http://localhost:8080/services/izmerenie-petli-faza-nul/`, обновить Ctrl+F5.
Проверить тексты, телефон/согласие, FAQ и отображение на телефоне.
Тестовые поведенческие проверки используют изолированные заглушки БД и почты;
они не отправляют менеджеру тестовых писем. Проверка настоящего подключения
к локальной БД и регистрация выполняются установщиком в вашем Docker.
Проверка подготовки локальной схемы: `php scripts/test-phase-neutral-schema.php`.

## GitHub, затем Beget

Из корня проекта:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\tools\phase-neutral\publish-github.ps1" -ProjectRoot (Get-Location).Path
```

Скрипт фиксирует только файлы этого патча, с автором Ekaterina Izotova,
не использует force push и проверяет отсутствие посторонних локальных коммитов.
Если main изменился, выполняется обычное слияние; конфликт требует отдельного
разрешения и повторной проверки. Изменённые после сборки файлы не публикуются.

После публикации скрипт напечатает `GITHUB_MAIN_OK=<commit>` и **готовую
однострочную команду Beget с этим commit**. Копия команды сохраняется в
`$env:TEMP\nwd-phase-neutral-beget.txt`. Вставлять её нужно в уже открытую
SSH-консоль `infonwt4@henry`, после зелёных проверок GitHub.

Серверный установщик использует PHP CLI 7.3, проверяет GitHub checks,
скачивает ровно опубликованный commit, проверяет исходные файлы, создаёт
приватную копию в `~/.nwd-production/phase-neutral-*`, активирует файлы и
добавляет страницу в нативные site/rewrite/site_parents/map_index.
Существующий URL не перезаписывается. Повторная установка уже созданной
неизменённой страницы не создаёт дубль. При ошибке активации выполняется откат.
В завершение проверяются публичные HTTP 200, тексты, форма и canonical.

Признак успешного деплоя: `PHASE_NEUTRAL_DEPLOY_OK=<commit>`.
Не продолжать вручную при `SOURCE_CONFLICT`: сначала сохранить и сверить
актуальный серверный файл. Предыдущий неудачный деплой запросов документов
мог оставить сервер на версии, отличающейся от текущего main.
