# Страница обслуживания электроустановок

Адрес: `/services/obsluzhivanie-elektroustanovok/`.

Страница использует существующую категорию shop и шаблон `themes/module.php`.
Проверка точного маршрута в `NwdEditorialPages::isMaintenance()` включает общее
оформление `editorial-pages.css` и отдельный `maintenance-editorial.css`.
Остальные страницы с тем же шаблоном сохраняют прежнюю ветку вывода.

## Контент и форма

- `shop.view.list.php` и `shop.view.id.php` передают только этот маршрут в
  `shop.view.maintenance_editorial.php`, независимо от типа записи shop в CMS.
- `themes/maintenance_service.php` перестраивает HTML из текущего `$result['text']`.
  Тексты и цены остаются в БД DIAFAN, не дублируются в PHP и не перезаписываются.
- Виды обслуживания, состав оборудования, категории, периодичность, требования и
  цены получают разные композиции. Длинные требования и дополнительные расценки
  доступны в нативных `details`; содержимое остаётся в серверном HTML без JavaScript.
- Названия известных разделов определяют их оформление. Незнакомые H2 и их
  содержимое выводятся отдельными обычными секциями. Неожиданная структура таблицы
  сохраняется в прокручиваемой обёртке.
- Динамические блоки 2–5, дочерние услуги, форма feedback 32 / t2, модальное окно
  `#modal`, обработчики согласия и отправки остаются штатными.
- Блок клиентов пропущен только для этого маршрута; города и счётчики сохранены.
  Уже существующее условие в footer отключает старый callback-free для этой страницы.

## Фотография

Новая фотография создана по предоставленному образцу: электромонтёр в сине-серой
форме обслуживает распределительный щит. Без надписей и логотипов, нейтральный свет,
естественные тени и фактура. Полный кадр 1448×1086 сохранён в
`images/maintenance/electrical-maintenance.webp` (quality 94); адаптивная версия
800×600 — `electrical-maintenance-small.webp`. Ресайз не обрезает кадр.
У изображения заданы размеры, srcset, sizes и высокий приоритет загрузки.
Слабая экранная коррекция brightness(.97)/saturate(.95) заменяет общий SVG-фильтр.
Исходный файл в `userfls` не изменяется.

## Проверки

- Синтаксис PHP 7.3 и состав Git проверяются штатными скриптами репозитория.
- Отдельный PHP-рендер на HTML действующей страницы проверяет сохранность слов,
  списков, категорий, цен, дополнительных разделов и ссылок.
- Макет с реальной шапкой, подвалом и формой проверен в браузере на ширинах
  1363, 1024, 768, 390 и 320 px; нет горизонтального переполнения и обрезки заголовка.
- Нативное раскрытие категории проверено в браузере. Анимация не скрывает контент
  при отключённом JS и отключается для prefers-reduced-motion.

Проверка макета использует HTML-образец из действующей CMS и реальные PHP-шаблоны,
но не является запуском всей CMS с копией производственной БД. Реальные заявки
и внешние письма в проверках не отправляются.

## Публикация

Локальные изменения → проверенный коммит GitHub → деплой этого коммита на Beget.
Миграция БД не нужна. Общие head/module/editorial_pages/shop.view.list следует
публиковать из актуального коммита, вместе с новыми PHP/CSS/JS и фотографиями.
Не заменять scripts.php, конфиг, пользовательские файлы или данные редакции.
