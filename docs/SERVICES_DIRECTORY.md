# Каталог услуг

Изменение включается только для точного маршрута `/services/`.
Вложенные страницы услуг, главная, цены, блог и меню не получают новый каталог.

## Вывод

`NwdEditorialPages::isServices()` включает класс `page-services`, общий стиль
внутренних страниц и отдельный `services-directory.css`. Текущий `site.php`
вызывает `show_services_content` только на этом маршруте.

Функция получает тот же результат штатного `show_text`, включая меню из БД.
`NwdServicesDirectory` перестраивает известный блок `section.services`: сохраняет
H1, названия направлений, идентификаторы групп и все элементы существующих списков
с их ссылками, атрибутами и текстом. На актуальной странице 45 услуг: 8/30/7.
Числа вычисляются из содержимого, а не хранятся в шаблоне.

Дополнительный контент внутри и вне каталога сохраняется. При неизвестной структуре
шаблон возвращает оригинальный HTML. База, slug, canonical, пункты меню не меняются.
HTML разбирается с явной UTF-8; исходные записи не пересохраняются.

Первый экран использует уже подготовленную фотографию из
`images/maintenance/electrical-maintenance.webp` и адаптивную версию 800×600.
Кадр целиком, без новых перекрашиваний; экранная коррекция совпадает с обслуживанием.

## Выбор услуги

Все ссылки выводятся сервером и доступны без JavaScript. Без JS показаны три
направления с якорной навигацией. Поиск и три вкладки появляются только после
успешной инициализации JS; обработчики старых вкладок не управляют новым каталогом.

Логика совпадает с прежним каталогом: по умолчанию открыто первое направление,
показан только его список, три вкладки переключают разделы без перезагрузки.
Первоначальный якорь известного раздела открывает соответствующую вкладку.
Общего списка «Все услуги» нет. На компьютере услуги размещены в две колонки,
на телефоне до 540 px — в одну. Каждая ссылка — отдельная светлая прямоугольная
плашка без тени, с шрифтом 16 px и полным названием.

Вкладки имеют роли tablist/tab/tabpanel, aria-selected и связь с панелью. Tab ведёт
на выбранную вкладку; стрелки, Home и End переключают направления. На телефоне
вкладки стоят вертикально и переключаются стрелками вверх/вниз.

Клиентский поиск поддерживает несколько слов, регистр, е/ё и распространённые
русские окончания. Поиск работает внутри выбранного раздела, количество найденного
озвучивается через aria-live. Переключение вкладки очищает запрос. Очистка и сброс
возвращают весь текущий раздел. Поиск ничего не отправляет на сервер и не затрагивает
обработку заявок.

CTA используют штатное окно `#modal`. На каталоге включена общая плашка звонка.
Блок клиентов пропускается только здесь; города, шапка, подвал, счётчики и форма
с согласием остаются штатными.

## Проверки

Сверены все 45 исходных ссылок/названий и три направления. Проверены сохранение
дополнительного CMS-контента и fallback, маршруты `/services/` и вложенных услуг,
отсутствие изменений вывода `site.php` для цен и обычных страниц, синтаксис PHP 7.3
и JS, состав Git. Базовое оформление ранее проверялось в браузере на ширинах
1363/1024/768/390/320 px. В текущей правке вкладок проверены в DOM открытие первого
раздела, переключение всех направлений, клавиатура, поиск, сброс, якорь раздела,
вывод без JS и изоляция других страниц. Hero, фото и блок консультации сверены
с прежним HTML и не изменились. Повторный визуальный прогон не выполнен:
общий предпросмотр занят другим проектом.

Макет проверялся с актуальным HTML сайта и реальным PHP-представлением. Это не
полный запуск DIAFAN с производственной БД. Реальные заявки не отправлялись.
