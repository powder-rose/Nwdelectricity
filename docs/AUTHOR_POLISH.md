Обновлены подпись в hero блога, подпись внутри статей и jobTitle автора
в JSON-LD. Формулировка хранится в одном месте: `redaktsiya/lib/author-role.php`.
Название компании в других словосочетаниях, например «Контакты
Спецэнергоразвития», не меняется.

CLI `scripts/update-author-role.php` заменяет именно эту должность в сохранённых
публичных текстовых полях DIAFAN, включая title_meta, description, keywords,
заголовки, контент и alt. Обрабатываются существующие таблицы публичных
модулей site, shop, shop_category, news, news_category, clauses,
clauses_category, bs, bs_elements, menu и images. Публичные таблицы
определены явным списком; заявки, почта, пользователи и настройки не читаются.
В panel_article обновляются title и строковые значения JSON payload, включая
SEO title, контент, alt, опубликованные статьи, черновики и отложенные статьи.
Кириллица в JSON с Unicode escape-последовательностями и HTML-сущности учтены.
Незатронутый JSON сохраняется побайтово. Пустые объекты остаются объектами.
Revision изменённой статьи повышается, чтобы открытая старая редакторская
форма не затёрла исправление. Расписание, URL, статусы и даты публикации
не изменяются. Встроенная отложенная публикация читает актуальный payload.
SEO title меняется только там, где есть прежняя подпись; названия услуг
и остальные части заголовков сохраняются.

Установка выполняет предвыкатную проверку, сохраняет приватную копию
изменяемых значений и обновляет данные транзакционно. Применение и откат
сверяют исходные значения каждого поля. Если после установки поле менялось
другим действием, автоматический откат его не перезаписывает. Повторное
применение идемпотентно. Таблицы с изменениями должны быть InnoDB; превышение
длины varchar или повреждённый JSON останавливают обновление до записи.
После применения очищаются сгенерированные кэши, правила доступа сохраняются.

«Открыть образец» оформлено как лаймовое действие высотой 66 px, шрифт 16 px,
контрастный индикатор плюс/минус, hover и видимый фокус с клавиатуры.
Открытая врезка показывает «Скрыть образец». Стиль общий для всех врезок,
в том числе для администраторов. Запрос документа, разрешение копирования,
форма согласия и почтовые уведомления работают через существующие обработчики.
Изменены CSS-исходник и публичный CSS; JS не изменялся. Новый параметр версии
стилей в статье обновляет браузерный кэш. Загрузка внешних шрифтов и библиотек
для этой правки не добавлялась.

## Применение

Распаковать ZIP и запустить корневой apply.ps1 с ProjectRoot в работающем
локальном Docker. Резервная копия файлов находится в
`.local/patch-backups/author-polish-*`; копия БД — в том же каталоге после
получения из `/tmp/nwd-author-polish-*.json` контейнера. Патч не меняет
config.php и не публикует сайт самостоятельно.

После локальной проверки:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\author-polish\publish-github.ps1 -ProjectRoot (Get-Location).Path
```

Скрипт сохраняет авторство Ekaterina Izotova, проверяет manifest, состав
индекса и исходящих коммитов, выполняет обычный fetch/merge/push в main.
Использует Windows TLS Schannel и HTTP/1.1 с проверкой сертификатов.
При сетевой ошибке останавливается; принудительной отправки нет.
После push выводится точная команда для SSH-консоли Beget и сохраняется
в `$env:TEMP\nwd-author-polish-beget.txt`. На Beget нужны успешные GitHub Checks
и PHP CLI 7.3; код берётся по точному SHA. Резервная копия хранится в
`~/.nwd-production/author-polish-*`. Ошибки активации запускают откат.

## Проверки

Проверены UTF-8, сущности, регистр подписи, SEO title, вложенный JSON,
сохранность расписания и маршрута, повторный запуск, существующие заявки
документов, PHP 7.3 и состав Git. В браузере проверены desktop и 320 px,
видимость новой подписи, цвет кнопки, открытие мышью и закрытие клавиатурой.
Установщик проверен с имитацией Docker; сценарий миграции — с изолированным
адаптером данных. Реальная БД заказчика и доставка писем в этой среде
не использовались. GitHub и Beget при подготовке архива не менялись.
