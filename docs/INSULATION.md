# Измерение сопротивления изоляции

Обновляется существующий URL `/services/zamer-soprotivleniya-izolyatsii/`.
Шесть блоков и публикационные тексты перенесены из ТЗ «004 — Измерение
сопротивления изоляции». Порядок: hero, объекты измерений, ситуации, этапы и
протокол, стоимость с формой, FAQ. Редакторские указания, поисковые частотности
и нормативные заметки на страницу не попадают. Ссылки относительные, без UTM.

Новый кадр с мегаомметром и SVG-иллюстрации подготовлены для этой страницы.
Цена, состав услуги, SEO Title/Description и ALT соответствуют ТЗ. Hero 60/40,
форма 55/45; на телефоне цена и кнопка предшествуют фотографии. Шапка и подвал
используют общие блоки без изменения их размеров или содержимого.

## Зависимости

Сначала устанавливается ранее согласованная страница электролаборатории и её
исправление проверки деплоя. Ссылку на эту услугу уже содержит её каталог.
Проверки зависимостей и хешей останавливают установку до замены чужих файлов.

## Локально

Распакуйте архив во временную папку и выполните в PowerShell:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$patch\apply.ps1" -ProjectRoot 'C:\Users\user\WebstormProjects\nwdelectricity'
```

Ожидается `INSULATION_LOCAL_OK`. Откройте
`http://localhost:8080/services/zamer-soprotivleniya-izolyatsii/` с Ctrl+F5.
Локальный bootstrap разрешён только при `NWD_LOCAL=1`, если страницы нет в
старом экспорте. На production создание отсутствующей страницы запрещено.

## GitHub и Beget

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File '.\tools\insulation\publish-github.ps1' -ProjectRoot (Get-Location).Path
```

Публикация проверяет файлы релиза, сохраняет авторство владельца, получает main
и печатает точную закреплённую на коммит команду Beget. После зелёных проверок
GitHub выполните напечатанную команду в существующей SSH-консоли Beget.
Успех: `INSULATION_DEPLOY_OK=<коммит>`.

## Данные и откат

Миграция находит исходную запись через rewrite; поддерживает site, shop_category
и shop. URL и ID не меняются. Обновляются тема, название, SEO, canonical,
индексация и анонс этой записи, если он существует. Старый основной текст и
медиа сохраняются в БД для отката, на новой странице их заменяют тексты ТЗ.
Если услуга — товар с одной штатной ценой, она обновляется до 9900. Несколько
вариантов цены требуют проверки и останавливают установку до записи.
Существующий sitemap сохраняется; недостающая запись добавляется только для
этого URL. Проверяются четыре смежные опубликованные услуги и обратная ссылка
в каталоге электролаборатории. Отсутствующие страницы не создаются на сервере.

Резервная копия файлов и изменяемых данных сохраняется вне document root.
При ошибке восстанавливаются файлы и запись страницы, включая цену и анонс.
Если редактор изменил эту запись после установки, автоматический откат
останавливается, чтобы сохранить независимые правки. Статьи панели, их
локальные черновики и настройки авторизации миграция не меняет.

## Заявки и проверка

Нативная форма 27 использует режим `insulation`: обязательный телефон,
необязательные имя/email/объём, отдельное согласие и идентификатор запроса.
Название услуги и канонический URL определяются сервером. Рекламные параметры
ограничены действующим списком и добавляются в сообщение. Очереди письма и
центрального сервиса создаются внутри действующей транзакции; повторы
идентичного запроса не дублируют заявку или уведомление.

События: `izolyatsiya_price_click`, `izolyatsiya_form_submit` (после success).
Ошибки и подтверждение точно соответствуют ТЗ. При ошибке введённые данные
сохраняются; общий обработчик снова делает кнопку доступной.

Проверки включают нативный парсер desktop/mobile, состав шести секций, SEO,
форму/согласие, миграцию и откат на всех трёх типах маршрута, цену карточки,
защиту от повтора, очередь письма и центрального сервиса. Проверка HTML
учитывает особенность libxml со счётчиками в head. Изолированные проверки
не отправляют реальные письма или заявки менеджерам. Доставку через рабочие
каналы следует проверять согласованной тестовой заявкой после публикации.
