## Перелинковка

На существующей странице лаборатории пока нет группы каталога с названием,
приведённым в ТЗ. Патч превращает существующий пункт «Срабатывание УЗО»
в ссылку на новую страницу, сохраняя исходный видимый текст и остальной HTML.
Новая группа каталога не создаётся. При отсутствии единственного подходящего
пункта либо при наличии другой ссылки установка останавливается до записи.
Маршрут лаборатории разрешается через rewrite с учётом module_name и
element_type: site/element, shop/cat или shop/element. Текст и его откат
относятся к фактической таблице site, shop_category или shop.
Изменение ссылки и регистрация страницы выполняются одной транзакцией;
старый текст лаборатории сохраняется в приватной резервной копии.
Если лаборатории нет в старом локальном дампе, apply.ps1 явно передаёт
--allow-missing-local-laboratory вместе с NWD_LOCAL=1. В этом случае создаётся
только новая страница, без выдуманных записей лаборатории; выводится
RCD_LOCAL_LABORATORY_SKIPPED. На Beget этот режим не используется. Попытка
передать флаг без NWD_LOCAL=1 отклоняется; неоднозначные маршруты и конфликты
существующего текста останавливают установку в любом режиме. Откат
проверяет, что текст после установки не был изменён другими действиями.

## Заявки и аналитика

Нативная форма feedback 27: телефон и согласие обязательны; имя, почта и
описание объекта необязательны. Используются реальные ID существующих полей.
Сообщения и уведомления содержат услугу «Проверка УЗО» и серверный canonical URL.
HTML-письмо ставится в действующую очередь на office@nwdelectricity.ru;
сохраняется действующий поток CRM/Hub. Повторы одного request ID не создают
дублей. Согласие по умолчанию выключено. Автозаполнение и Enter не отправляют
форму; требуется активация кнопки. При ошибке данные сохраняются.

Метрика 114341229: `proverka_uzo_price_click` при переходе к форме,
`proverka_uzo_form_submit` после подтверждённого сохранения заявки сервером.
UTM/yclid/gclid сохраняются в нативном сообщении. В цели не передаются данные
посетителя. Описание услуги не определяется произвольным Referer из браузера.

## Локальная установка

Требуется установленный предыдущий выпуск «фаза-нуль», Docker Desktop,
`compose.local.yaml` и `.local/docker.env`. Корневой `apply.ps1` проверяет
хэши до копирования, сохраняет копию в `.local/patch-backups/rcd-*`, запускает
проверки в Docker и регистрирует страницу вместе с обратной ссылкой.
При ошибке восстанавливает изменённые файлы. Рабочие config.php, SMTP,
.htaccess, статьи и загрузки не заменяются. В старом локальном дампе только
отсутствующие служебные таблицы заявок подготавливаются с NWD_LOCAL=1.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$patch\apply.ps1" -ProjectRoot "C:\Users\user\WebstormProjects\nwdelectricity"
```

После `RCD_LOCAL_OK`: открыть `http://localhost:8080/services/proverka-uzo/`,
обновить Ctrl+F5. Подготовка БД выполняется именно в вашем Docker.

Проверки PHP 7.3: test-rcd.php (серверная валидация, запись, почтовая очередь,
Hub, защита повторов), test-rcd-render.php (настоящий DIAFAN парсер, контроллер,
модель и view формы с изолированными адаптерами), test-rcd-lab-link.php
(сохранность текста лаборатории), test-rcd-laboratory.php (типы маршрутов,
отсутствующая лаборатория в старом локальном дампе, строгий режим Beget
и допустимые таблицы отката). Повторно проверяются существующие формы
«фаза-нуль» и запроса документов. Эти проверки не отправляют внешние письма
и не заменяют реальную проверку доставки после публикации. Визуальный просмотр
использует тот же проверенный HTML нативного рендера с общей шапкой/подвалом.
Полного локального дампа сайта в среде подготовки патча нет.

## GitHub и Beget

После локального просмотра:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\tools\rcd\publish-github.ps1" -ProjectRoot (Get-Location).Path
```

Фиксируются только файлы патча, автор Ekaterina Izotova. Нет force push.
Публикация останавливается при посторонних исходящих изменениях или при
несовпадении проверенных файлов. Скрипт выводит `GITHUB_MAIN_OK=<commit>`
и готовую команду Beget, закреплённую за этим commit. Команда сохраняется
в `$env:TEMP\nwd-rcd-beget.txt`. Её нужно вставить в SSH-консоль Beget после
зелёных проверок GitHub. Точную команду генерирует публикация, вручную менять
commit или подставлять старый выпуск не нужно.

Beget: проверка CI, загрузка точного исходника, хэши файлов и зависимостей,
приватная копия `~/.nwd-production/rcd-*`, PHP 7.3, проверки без внешних
отправок, активация, транзакция страницы/ссылки, очистка кэша. При ошибке —
откат. В конце проверяются HTTP 200, контент и canonical новой страницы,
а также доступность предыдущей страницы. Готовность: `RCD_DEPLOY_OK=<commit>`.
Агент не публикует патч автоматически: сначала выполняется локальный просмотр.
