# Фиксированная плашка «Заказать звонок»

Плашка главной добавлена через общий блок модальных окон на семь переработанных услуг:
измерение петли «фаза-нуль», проверка УЗО, испытание электроинструмента,
электролаборатория, измерение сопротивления изоляции, измерение сопротивления
заземления и проверка автоматических выключателей.

Используются существующее окно `#modal`, Fancybox и нативная форма 27. Новых
обработчиков отправки и сторонних сервисов нет. Плашка закреплена справа внизу;
на телефоне, как на главной, остаётся кнопка с телефоном и доступным названием.
Во время открытия окна или мобильного меню она скрыта. Предусмотрены фокус
клавиатуры, безопасный отступ телефона и reduced motion.

Старые общие разделы и список статей уже содержат свою плашку; дубликаты не
добавляются. Страницы самих статей сохраняют ранее согласованное поведение.
База, API, редактор, черновики и конфигурация форм не изменяются.

## Установка

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$patch\apply.ps1" -ProjectRoot $project
```

Результат: `CALLBACK_LOCAL_OK`. Установщик проверяет исходные файлы и сохраняет
копию в `.local/patch-backups`. Docker для копирования файлов не требуется.
Открыть локальную услугу и обновить Ctrl+F5.

## Публикация

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$project\tools\callback\publish-github.ps1" -ProjectRoot $project
```

После зелёных GitHub checks выполнить напечатанную скриптом команду в SSH Beget.
Результат: `CALLBACK_DEPLOY_OK=<коммит>`. Проверяются исходные хеши, PHP 7.3,
публичные страницы и CSS. При ошибке восстанавливаются файлы. Сервисы не
перезапускаются. Страница, чей редизайн ещё не активирован на сервере, получает
плашку при последующей активации; скрипт помечает её как `PAGE_NOT_REDESIGNED`.

Скрипт GitHub допускает ранее подготовленную страницу выключателей в том же
исходящем наборе коммитов. Деплой плашки переносит только файлы этого патча;
активация самой страницы выключателей выполняется её отдельной командой.
