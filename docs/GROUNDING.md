# Измерение сопротивления заземляющих устройств

Обновляется существующий URL `/services/proverka-soprotivleniya-zazemliteley/`.
Публикационные тексты и порядок шести блоков сохранены из ТЗ «005 — измерение
сопротивления заземляющих устройств». Редакторские заметки, Wordstat и нормативные
указания не добавляются на страницу. Страница монтажа контура не изменяется.

Первый экран использует новый кадр измерений на территории объекта. Иллюстрации
связывают внешний вид страницы с темой заземления. Блок проверки, ситуации и
этапы имеют разные композиции. Общие шапка, подвал, формы и фирменные шрифты
сохраняются. На телефоне цена и кнопка расположены до фотографии.

## Локальная установка

Архив содержит `apply.ps1`, полезную нагрузку и `changes.patch`.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$patch\apply.ps1" -ProjectRoot 'C:\Users\user\WebstormProjects\nwdelectricity'
```

Ожидается `GROUNDING_LOCAL_OK`. Просмотр:
`http://localhost:8080/services/proverka-soprotivleniya-zazemliteley/` с Ctrl+F5.

Установщик сверяет версии зависимостей и заменяемых файлов, создаёт резервную
копию и проверяет PHP и нативный рендер. Старые локальные экспорты могут не
содержать записи: только при `NWD_LOCAL=1` разрешён локальный bootstrap.
Производственное создание отсутствующей страницы запрещено.

## Публикация

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File '.\tools\grounding\publish-github.ps1' -ProjectRoot (Get-Location).Path
```

Скрипт публикует только согласованные файлы, сохраняет авторство владельца и
печатает точную команду Beget, закреплённую на коммит. Её выполняют в SSH-консоли
после зелёных GitHub checks. Итог: `GROUNDING_DEPLOY_OK=<коммит>`.

## Данные и откат

Через rewrite определяется исходная запись site, shop_category или shop.
Сохраняются URL и ID. Обновляются тема, имя, title, description, canonical,
индексация и анонс. Для товара с одной ценой она обновляется до 9900; несколько
вариантов цены останавливают установку до записи. Старый основной текст и
медиа остаются в БД для восстановления, новый шаблон их не выводит.

Существующий sitemap не перезаписывается; отсутствующая запись добавляется
только для этой услуги. Проверяются опубликованные пути металлосвязи,
электролаборатории, технического отчёта и паспорта. Каталог лаборатории уже
содержит правильную обратную ссылку и не изменяется.

Резервные копии Beget находятся вне document root, локальные — в
`.local/patch-backups`. Ошибки запускают откат изменённых данных и файлов.
Независимая правка записи редактором останавливает автоматическое восстановление
этой записи. Статьи панели, черновики, авторизация и API не меняются.

## Заявки и проверки

Нативная форма 27 использует отдельный режим `grounding`. Обязателен телефон;
имя, почта и описание необязательны. Согласие из действующего компонента
изначально не отмечено. Название услуги и canonical определяются сервером.
Действующие очереди письма и центрального сервиса получают поля заявки и
ограниченные рекламные параметры. Повторы не создают дубли заявки или письма.

События: `zazemlenie_price_click` и `zazemlenie_form_submit` после успеха сервера.
При ошибке сохраняются значения и разблокируется кнопка. Состояния и подписи
взяты из ТЗ. Нативный обработчик остальных услуг остаётся действующим.

Проверяются поведение формы и очередей, миграция на трёх типах записи и откат,
desktop/mobile парсер CMS, публичный HTML, SEO, ссылки и структура. Проверка H1
учитывает переносы строк и поведение libxml 2.7.8 на Beget. Каждая проверка
деплоя выводит имя и сообщение об ошибке. Изолированные тесты не отправляют
реальные заявки; доставку через рабочие каналы проверяют согласованной тестовой
заявкой после публикации.
