Редактор адаптирован из проекта «Паспорт Доступности», раздел написания статей, по образцу «Паспорта Безопасности». Интерфейс использует React и Tiptap. В браузерной сборке сохранены лицензионные комментарии зависимостей.

Для изменения интерфейса выполните `npm ci` и `npm run build` из этого каталога. На PHP-сервер загружаются только готовые ресурсы из `redaktsiya/assets/`.
